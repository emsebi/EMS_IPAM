# قالب ماژول EMS IPAM

این پوشه فقط نمونه قرارداد ماژول است و توسط Core بارگذاری نمی‌شود. برای هر قابلیت جدید، یک پوشه مستقل در `modules/<module-id>/` ایجاد شود. فایل `module.json` شناسه، نسخه، مسیر رابط کاربری، سطح دسترسی و وابستگی‌ها را مشخص می‌کند.

خرابی یا نبود یک ماژول نباید مانع بالا آمدن Core شود.
