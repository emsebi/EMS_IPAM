راهنمای انتشار نسخه 0.6.0 در GitHub

مخزن مقصد:
https://github.com/emsebi/EMS_IPAM

1) از شاخه main یک نسخه پشتیبان یا Branch موقت بسازید.

2) فایل EMS-IPAM-Network-Map-v0.6.0-GitHub.zip را Extract کنید.

3) وارد پوشه استخراج‌شده EMS_IPAM_v0.6.0 شوید.

4) تمام محتویات داخل این پوشه را مستقیماً در ریشه مخزن EMS_IPAM بارگذاری کنید و جایگزینی فایل‌های هم‌نام را بپذیرید.

مهم:
- خود فایل ZIP را داخل GitHub نریزید.
- پوشه EMS_IPAM_v0.6.0 را به‌صورت یک زیرپوشه داخل مخزن نریزید.
- مسیر نهایی باید مانند compose.yml و install.sh در ریشه مخزن باشد.
- فایل واقعی .env سرور را هرگز در GitHub قرار ندهید؛ فقط .env.example مجاز است.

5) بعد از Commit، برای نصب یا ارتقا اجرا کنید:
curl -fsSL https://raw.githubusercontent.com/emsebi/EMS_IPAM/main/install.sh | sudo bash

6) در نصب تازه گزینه 1 و در سرور دارای نسخه قبلی گزینه 2 را انتخاب کنید.

هشدار ارتقا:
نسخه 0.6 رمزهای قدیمی تجهیزات و اطلاعات پایش خودکار را برای همیشه از دیتابیس پاک می‌کند. قبل از اجرا از تصمیم خود مطمئن باشید. بکاپ تمیز پس از پاک‌سازی ساخته می‌شود.

7) پس از موفقیت، نقشه شبکه از این مسیر است:
http://SERVER-IP:PORT/network-map/

8) برای به‌روزرسانی‌های بعدی فقط ماژول نقشه:
curl -fsSL https://raw.githubusercontent.com/emsebi/EMS_IPAM/main/modules/network-map/install.sh | sudo bash -s -- update

این دستور فقط کانتینر نقشه را Build می‌کند و مدیریت IP یا دیتابیس را Build نمی‌کند.

9) فایل کلاینت ویندوز باید در این مسیر باشد:
docker-app/public/downloads/EMS-IPAM-Windows-Client-v0.6.0.zip

10) پیش از انتشار، آزمون‌ها و SHA256SUMS.txt را بررسی کنید.
