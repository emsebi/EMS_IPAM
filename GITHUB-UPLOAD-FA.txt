EMS IPAM Core v0.7.0

این خروجی را در Root مخزن GitHub قرار دهید.
هسته شامل IPAM و دیتابیس است.
ماژول‌ها بعداً فقط به صورت پوشه جدید زیر modules/ اضافه می‌شوند.

مراحل پیشنهادی:
1) محتویات این پوشه را Commit کنید.
2) روی سرور: sudo bash install.sh
3) برای نسخه بعد: sudo /opt/ems-ipam/install.sh update
4) پس از اضافه شدن ماژول: sudo /opt/ems-ipam/install.sh modules
