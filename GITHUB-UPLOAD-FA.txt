روش اعمال روی کامپیوتری که Git و اجازه Push دارد:
1. ZIP را استخراج کنید.
2. در همان پوشه کنار GITHUB-UPDATE.patch اجرا کنید:

git clone https://github.com/emsebi/EMS_IPAM.git EMS_IPAM-git
cd EMS_IPAM-git
git apply --check ../GITHUB-UPDATE.patch
git apply ../GITHUB-UPDATE.patch
git add -A

git push origin main

اگر git apply --check خطا داد، ادامه ندهید؛ مخزن پس از آماده‌سازی Patch تغییر کرده و باید تغییرات ادغام شوند. اگر Push خطای دسترسی داد، حساب GitHub باید مجوز نوشتن داشته باشد. نسخه‌های قبلی در تاریخچه Git باقی می‌مانند.
