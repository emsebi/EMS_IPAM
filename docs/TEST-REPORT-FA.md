# گزارش آزمون نسخه ۰.۵.۲

تاریخ بررسی: ۲۱ شهریور ۱۴۰۵ / ۱۲ سپتامبر ۲۰۲۶

## نتیجه

- آزمون‌های خودکار: ۳۲ مورد موفق از ۳۲ مورد
- خطای آزمون: صفر
- بررسی نحو فایل‌های JavaScript سرور و رابط: موفق
- بررسی نحو اسکریپت نصب Linux با Bash: موفق
- بررسی یکپارچگی بستهٔ ZIP کلاینت ویندوز: موفق
- بررسی ابعاد چهار تصویر GitHub: هر چهار تصویر ۱۶۰۰ در ۹۰۰ پیکسل

## بخش‌های پوشش‌داده‌شده

- ورود و هش امن رمزها
- رمزگذاری اطلاعات حساس تجهیزات
- سطح دسترسی شرکت و فضای آدرس‌دهی
- مدیریت رنج و زیرشبکه تا `/32`
- ایجاد، ویرایش، حذف نرم و بازگردانی
- پشتیبان دستی و خودکار و حفظ فایل‌ها هنگام به‌روزرسانی
- خروجی و ورود بستهٔ زیرشبکه بدون اطلاعات محرمانه
- رابط شرکت‌ها، تجهیزات، رادیوها و ناوبری مرورگر
- تولید اسکریپت سادهٔ فقط‌خواندنی MikroTik برای API بدون Certificate و روش‌های پیشرفتهٔ اختیاری
- محاسبهٔ خودکار Gateway از آدرس شبکه
- نمایش ابزارهای اتصال در جدول عمودی و جلوگیری از بسته‌شدن ناخواستهٔ منو
- جست‌وجوی AP با نام، IP، SSID، MAC، شرکت و رنج
- تم نئون تیره و خوانایی کامل جدول‌های IP
- ساختار پروتکل ویندوز، شناسایی ابزارها و عدم انتقال رمز در لینک
- وجود دانلود مستقیم کلاینت در سرویس وب
- ارسال صرفاً `IP:PORT` از کلاینت ویندوز به WinBox
- فهرست بکاپ MikroTik، عدم ذخیرهٔ رمز و تاریخ شمسی خروجی‌ها
- گزارش مستقل آنلاین‌بودن IP و Subnet
- تنظیم فونت و اندازهٔ نوشته
- رابط نسخه‌دار برای اتصال پروژهٔ مستقل نقشه شبکه

فرمان آزمون:

```bash
node --test --test-concurrency=1 docker-app/tests/*.test.mjs
```

اجرای عملی WinBox، SSH، پینگ و دریافت سیگنال از تجهیزات واقعی پس از نصب در شبکهٔ مقصد با دکمه‌های آزمایش انجام می‌شود؛ مسیر شبکه، RouterOS، پورت‌ها و برنامه‌های نصب‌شده در هر سازمان متفاوت‌اند. در محیط ساخت، Docker و تجهیز واقعی شبکه در دسترس نبود؛ بنابراین گزارش حاضر موفقیت آزمون‌های خودکار، بررسی نحو، ساختار بسته‌ها و بازبینی تصویری رابط را ثبت می‌کند و ادعای آزمون روی شبکهٔ مقصد ندارد.
