# گزارش آزمون نسخه ۰.۵.۰

تاریخ بررسی: ۱۶ شهریور ۱۴۰۵ / ۷ سپتامبر ۲۰۲۶

## نتیجه

- آزمون‌های خودکار: ۲۶ مورد موفق از ۲۶ مورد
- خطای آزمون: صفر
- بررسی نحو فایل‌های JavaScript سرور و رابط: موفق
- بررسی نحو اسکریپت نصب Linux با Bash: موفق
- بررسی یکپارچگی بستهٔ ZIP کلاینت ویندوز: موفق
- بررسی ابعاد چهار تصویر GitHub: هر چهار تصویر ۱۶۰۰ در ۹۰۰ پیکسل

## بخش‌های پوشش‌داده‌شده

- ورود و هش امن رمزها
- رمزگذاری اطلاعات حساس تجهیزات
- سطح دسترسی شرکت و فضای آدرس‌دهی
- مدیریت رنج و زیرشبکه تا `/32`
- ایجاد، ویرایش، حذف نرم و بازگردانی
- پشتیبان دستی و خودکار و حفظ فایل‌ها هنگام به‌روزرسانی
- خروجی و ورود بستهٔ زیرشبکه بدون اطلاعات محرمانه
- رابط شرکت‌ها، تجهیزات، رادیوها و ناوبری مرورگر
- تولید اسکریپت فقط خواندنی MikroTik برای REST و API-SSL
- ساختار پروتکل ویندوز، شناسایی ابزارها و عدم انتقال رمز در لینک
- وجود دانلود مستقیم کلاینت در سرویس وب

فرمان آزمون:

```bash
node --test --test-concurrency=1 docker-app/tests/*.test.mjs
```

آزمون عملی اتصال به یک روتر واقعی یا اجرای رابط گرافیکی Windows باید پس از نصب در شبکهٔ مقصد با دکمهٔ «آزمایش ارتباط» انجام شود؛ زیرا گواهی، مسیر شبکه و برنامه‌های نصب‌شده در هر سازمان متفاوت‌اند.
