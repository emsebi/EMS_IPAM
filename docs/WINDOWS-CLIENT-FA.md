# راهنمای کلاینت اتصال ویندوز

کلاینت ویندوز، پروتکل محلی زیر را در حساب کاربری ویندوز ثبت می‌کند:

```text
emsipam://
```

با انتخاب دکمهٔ اتصال در سامانه، مرورگر آدرس، پورت، ابزار و در صورت موجودبودن نام کاربری را به کلاینت می‌دهد. کلاینت سپس برنامهٔ مناسب را روی همان رایانه اجرا می‌کند.

## دانلود

دانلود مستقیم از GitHub:

[EMS IPAM Windows Client v0.5.0](https://github.com/emsebi/EMS_IPAM/raw/refs/heads/main/docker-app/public/downloads/EMS-IPAM-Windows-Client-v0.5.0.zip)

دانلود از سرور نصب‌شده:

```text
http://SERVER-IP:PORT/client.html
```

## نصب

۱. فایل فشرده را دانلود و کامل استخراج کنید.

۲. روی فایل زیر دوبار کلیک کنید:

```text
Install.cmd
```

۳. پنجرهٔ نصب، ابزارهای پیدا‌شده را نمایش می‌دهد و پروتکل محلی را برای همان کاربر ویندوز ثبت می‌کند.

۴. مرورگر را دوباره باز کنید و در سامانه، کنار تجهیز یا IP روی «اتصال» بزنید.

۵. هنگام اولین اجرا، اجازهٔ بازشدن کلاینت را در مرورگر تأیید کنید.

## ابزارهای پشتیبانی‌شده

| ابزار | روش اجرا |
|---|---|
| WinBox | آدرس، پورت و نام کاربری به برنامه داده می‌شود. |
| Remote Desktop | آدرس و پورت با گزینهٔ درخواست اطلاعات ورود باز می‌شود. |
| SSH / PuTTY | نام کاربری، آدرس و پورت برای اتصال استفاده می‌شود. |
| VNC Viewer | آدرس و پورت در Viewer نصب‌شده باز می‌شود. |
| HTTP / HTTPS | نشانی در مرورگر پیش‌فرض باز می‌شود و کلاینت لازم نیست. |

کلاینت ابتدا رجیستری استاندارد App Paths، سپس PATH و محل‌های رایج نصب را بررسی می‌کند. اگر ابزار پیدا نشود، پنجرهٔ انتخاب فایل باز می‌شود. مسیر انتخاب‌شده برای دفعات بعد در فایل تنظیمات همان کاربر ذخیره می‌شود.

## امنیت

- رمز عبور داخل `emsipam://` قرار نمی‌گیرد.
- رمز عبور در خط فرمان برنامهٔ مقصد نوشته نمی‌شود.
- ورود رمز در خود WinBox، Remote Desktop، PuTTY یا VNC انجام می‌شود.
- کلاینت فقط نشانی‌هایی را می‌پذیرد که قالب و ابزار آن‌ها معتبر باشد.
- نصب در محدودهٔ حساب کاربر انجام می‌شود و تغییری در تنظیمات شبکه ایجاد نمی‌کند.

## حذف

برای حذف ثبت پروتکل و تنظیمات کلاینت، فایل زیر را اجرا کنید:

```text
Uninstall-EMS-Client.ps1
```

در صورت بسته‌بودن اجرای فایل‌های PowerShell، از منوی راست‌کلیک گزینهٔ Run with PowerShell را انتخاب کنید.
