# EMS_IPAM 1.7.1 — integrated release checkpoint

Date: 2026-11-11

## Scope
- Promote **Radio 2.3.0** multi-AP documentation view to the current Core, without merging the old Radio branch wholesale.
- Larger map with right-side AP/Station visibility controls, Show all / Hide all, correct parent-linked geographic lines, and one combined Radio Topology & Stations panel.
- Keep existing PostgreSQL-backed radio GPS and uplink records, Core IPAM, Inventory, RADIUS Operations, and network-map functionality unchanged.
- Publish consistent version metadata for Core, Docker Compose, installer and browser assets. Keep the release installer on the GitHub `main` branch.
- The README includes links to the six **real Playwright-derived sample screenshots** already committed under `docs/screenshots/real`. The dedicated `radio-multi-ap-dashboard.png` is produced by the Playwright browser suite and is automatically published by the successful main CI screenshot job, never generated or simulated.

## Validation expectations
- Core Node tests, database migration/PostgreSQL tests, browser/API multi-AP coverage, and Docker stack builds must all pass before merging this release branch.
- Browser checks two APs with correct Station parents, two links, independent Station/AP toggles, map height, responsive panel and single topology; screenshot is produced from a test fixture, **not** the user's production VM.
- Confirm real deployment and router authentication separately; automated CI is not proof of a live site.

## Update
The existing supported installer detects installations with `/opt/ems-ipam/.ems-ipam-install` and `/var/lib/ems-ipam/.env`. Run the official installer and select **2 (Update)**; it performs a required compressed PostgreSQL backup before replacing application files, and preserves existing database volume and environment. Do not use option 5; it destroys the application data. Review the RADIUS UDP 1812/1813 ports for conflicts with any separately managed FreeRADIUS stack.

## Known incomplete work
- Live automatic full network discovery, MAC Trace and 802.1X/NAC enforcement are not completed.
- RADIUS Full/Read authentication on production RouterOS devices remains an open real-device acceptance item.
- The Radio map documents saved GPS straight-line links; it does not monitor live radio quality or push changes.
- Database migrations are not automatically reverted by restoring old application files.
