# نقشهٔ شبکه 0.2.0-lab.3 — نصب‌شده در ۲ نوامبر ۲۰۲۶

نسخهٔ نصب‌شده: [`588ba9f`](https://github.com/emsebi/EMS_IPAM/commit/588ba9f86a1731ee12c5308ddef2e755131352dc)، حاصل ادغام [PR #9](https://github.com/emsebi/EMS_IPAM/pull/9). API ردیابی IP از PR #8 نیز در این نصب موجود است.

## تغییر قابل استفاده

در «نقشه و تجهیزات»، نوع جست‌وجو را روی IPv4 بگذارید و IP را جست‌وجو کنید. همهٔ رکوردهای ذخیره‌شدهٔ همان شرکت، نام شبکه و زمان ویرایش رکورد نمایش داده می‌شوند. با انتخاب MAC، شواهد ذخیره‌شدهٔ سوئیچ، پورت و VLAN همراه منبع، زمان مشاهده و وضعیت قدیمی‌بودن باز می‌شوند. جست‌وجوی قبلی MAC حفظ شده است.

این جست‌وجو پایش یا خواندن MAC از تجهیزات را آغاز نمی‌کند. انتساب IP به MAC از Inventory است و مشاهدهٔ زندهٔ ARP محسوب نمی‌شود؛ نتیجه صریحاً نامطمئن است. رکورد ویرایش‌شده با مشاهدهٔ شبکه یکی نیست. IPv6 در این مرحله اضافه نشده است.
