# EMS_IPAM v1.7.0-rc.3 — Release checkpoint

تاریخ: ۲۰۲۶-۱۰-۲۵ / ۱۴۰۵-۰۸-۰۳

این نسخه نقطهٔ ذخیرهٔ امکانات فعلی برای ادامهٔ مرحله‌ای پروژه است. مبنای کد، آخرین commit ثبت‌شدهٔ `work/i18n-personnel-foundation` با شناسهٔ `2b889709064b01872f2d6ff33eeeb73b0f0a49da` است.

## امکانات این مرحله

- Core، IPAM، فهرست تجهیزات، Device Types، Radio با انتخاب AP و Stationهای مربوط، MAC/پرسنل و کلاینت ویندوز 0.8.0.
- RADIUS Device Access: NAS، مجموعهٔ تجهیزات، پروفایل دسترسی، کاربر، قالب کانفیگ دستی و گزارش/لاگ عملیاتی.
- گزارش‌های خلاصه و رخدادهای مدیریتی؛ رابط فارسی و انگلیسی.
- حمایت مالی اختیاری در منوی کاربر ← دربارهٔ EMS_IPAM و انتهای README، با آدرس عمومی USDT روی TRON (TRC20) و BTC روی Bitcoin، QR محلی و دکمهٔ کپی.
- کپی آدرس روی HTTPS و HTTP داخلی با انتخاب دستی در صورت رد شدن دسترسی کلیپ‌بورد.
- اصلاح جداسازی رکورد LLDP تا Chassis ID از پورت محلی جدا نشود؛ افزودن تست پارسر به CI.

## حدود این نقطهٔ ذخیره

کشف زندهٔ کامل نقشه، ذخیرهٔ حساب Discovery، MAC Trace و اعمال سیاست 802.1X/NAC هنوز تکمیل نشده‌اند. نقشهٔ دستی، API ذخیرهٔ Snapshot و پارسر آفلاین LLDP/CDP موجودند. فایل‌های در حال توسعهٔ ماژول نقشه وارد این انتشار نشده‌اند.

داده‌های تصاویر از محیط آزمایشی با آدرس‌های نمونهٔ 192.0.2.0/24 هستند. این تغییر نیاز به تغییر کانفیگ تجهیزات شبکه ندارد.

## اعتبارسنجی

- صحت checksum آدرس TRON و آدرس Bitcoin بررسی شد.
- هر دو تصویر QR با decoder مستقل خوانده شدند و دقیقاً با URI ارسالی مالک پروژه مطابقت دارند؛ هیچ انتقال وجهی انجام نشده است.
- تست‌های JavaScript: ۱۸۵ تست Core و ۴۳ تست ماژول‌ها، همگی موفق.
- ۱۵ سناریوی مرورگر/API با HTTP واقعی و دیتابیس موقت PGlite موفق شدند؛ آدرس و لینک پرداخت، بارگذاری QR، کپی واقعی و fallback، زبان فارسی/انگلیسی و عرض‌های ۳۹۰، ۶۰۰ و ۱۴۴۰ بررسی شدند.
- [CI کد همین نسخه موفق است](https://github.com/emsebi/EMS_IPAM/actions/runs/40137314706): تست‌های JavaScript، ۳۰ تست supervisor، ۲ تست تنظیم لاگ و تست مرورگر. سه بررسی مالکیت UDP در محیط محدود محلی موفق نبودند؛ همان تست‌ها بدون تغییر روی runner لینوکس GitHub موفق شدند.
- تصاویر و [گزارش تست](../TEST-REPORT-FA.md) همراه سورس ثبت شده‌اند. مرورگر محلی Chromium 153 است؛ PGlite جایگزین تستی pg است و تست اتصال PostgreSQL واقعی محسوب نمی‌شود.
- آخرین استقرار آزمایشی و smoke مربوط به Docker/PostgreSQL/FreeRADIUS روی همان کد مبنا: [موفق](https://github.com/emsebi/EMS_IPAM/actions/runs/39882213095). این نتیجه مربوط به commit مبناست؛ برای نسخهٔ جدید ادعای اجرای Docker در محیط محلی نمی‌شود.
