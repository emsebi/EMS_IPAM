# راهنمای بکاپ کانفیگ MikroTik

## این قابلیت چه چیزی ذخیره می‌کند؟

سامانه با SSH به RouterOS متصل می‌شود، ابتدا Identity و نسخهٔ دستگاه را می‌خواند و سپس خروجی متنی کانفیگ را با اطلاعات حساس دریافت می‌کند. فایل با پسوند `.rsc`، نام دستگاه و تاریخ شمسی ذخیره می‌شود.

این قابلیت فایل باینری `/system backup save` نمی‌سازد. خروجی متنی برای مشاهده، جست‌وجو، کپی و واردکردن مجدد دستورها مناسب‌تر است و بین مدل‌های مختلف RouterOS وابستگی کمتری دارد.

## اطلاعاتی که ذخیره می‌شوند

- نام یا عنوان دستگاه
- IP و پورت SSH
- نام کاربری
- نسخهٔ انتخابی RouterOS یا حالت تشخیص خودکار
- تاریخچهٔ فایل‌های موفق و نتیجهٔ آخرین تلاش

رمز عبور دستگاه ذخیره نمی‌شود. متن زیر در صفحهٔ بکاپ نیز همیشه نمایش داده می‌شود:

> پسوردها جهت موارد امنیتی فقط در زمان اجرا استفاده شده و در هیچ قسمتی ذخیره نمیگردد

بعد از خروج و ورود دوباره، تمام مشخصات به‌جز رمز باقی می‌مانند و کادر رمز خالی است.

## آماده‌سازی MikroTik

سرویس SSH باید روی دستگاه فعال باشد. نمونهٔ ساده:

```routeros
/ip/service/set ssh disabled=no port=22
```

برای گرفتن خروجی دارای اطلاعات حساس، کاربر بکاپ باید مجوزهای `read`، `ssh` و `sensitive` داشته باشد. نمونهٔ ساخت یک گروه و کاربر اختصاصی:

```routeros
/user/group/add name=ems-backup policy=read,ssh,sensitive
/user/add name=ems-backup group=ems-backup password="رمز دلخواه شما"
```

اگر گروه یا کاربر از قبل وجود دارد، به‌جای افزودن دوباره، همان مورد را در WinBox یا Terminal ویرایش کنید. سامانه Firewall دستگاه را تغییر نمی‌دهد و IPهای مجاز را مطابق سیاست شبکهٔ خودتان محدود می‌کنید.

## افزودن دستگاه به فهرست

سه راه وجود دارد:

1. در فرم اطلاعات یک IP، گزینهٔ «افزودن به لیست بکاپ» را فعال کنید.
2. در IP معتبر شرکت یا شعبه، همان گزینه را فعال کنید.
3. در پنجرهٔ بکاپ کانفیگ، IP مستقلی را دستی اضافه کنید؛ این روش برای دستگاهی مناسب است که هنوز در هیچ رنجی ثبت نشده است.

در هر سه روش فقط IP، پورت، نام کاربری و نسخه نگهداری می‌شوند.

## اجرای بکاپ

1. پنجرهٔ «بکاپ کانفیگ میکروتیک» را باز کنید.
2. دستگاه‌ها را انتخاب یا از «انتخاب همه» استفاده کنید.
3. رمز هر دستگاه را در کادر خالی همان ردیف وارد کنید.
4. «بکاپ گزینه‌های انتخاب‌شده» را بزنید.

نتیجهٔ هر دستگاه مستقل نمایش داده می‌شود:

- موفق: ردیف سبز می‌شود، فایل در تاریخچه ثبت و تیک انتخاب برداشته می‌شود.
- ناموفق: ردیف قرمز می‌شود، علت خطا نمایش داده و تیک برای تلاش بعدی روشن می‌ماند.

بعد از اجرا، تمام کادرهای رمز پاک می‌شوند.

## دستورات نسخه‌ها

سامانه در حالت خودکار ابتدا نسخه را تشخیص می‌دهد:

```routeros
/system identity print
/system resource print
```

برای RouterOS v7:

```routeros
/export show-sensitive
```

برای RouterOS v6:

```routeros
/export hide-sensitive=no
```

اگر تشخیص خودکار نسخهٔ ۷ باشد اما دستور جدید پشتیبانی نشود، یک‌بار دستور نسخهٔ ۶ آزمایش می‌شود.

## تاریخچه

در ردیف هر دستگاه، «لیست بکاپ‌ها» تاریخچه را باز می‌کند. هر نسخه دارای این گزینه‌هاست:

- نمایش متن کانفیگ
- کپی کامل متن
- دانلود فایل `.rsc`
- حذف همان نسخه

تعداد نسخه‌های نگهداری‌شده برای هر دستگاه از تنظیمات بکاپ قابل تعیین است.
