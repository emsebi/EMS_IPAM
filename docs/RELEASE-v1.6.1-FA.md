# انتشار EMS IPAM v1.6.1

این انتشار هفت ایراد گزارش‌شده در Base + IPAM + Radio را اصلاح می‌کند:

1. در پرسنل فقط نام و نام خانوادگی الزامی است؛ کد و تمام مشخصات دیگر اختیاری‌اند.
2. مسیر افزودن و ویرایش تجهیز از Inventory مستقیماً Context همان IP را بارگذاری می‌کند و خطای ذخیره داخل فرم دیده می‌شود.
3. کلاینت Windows v0.7.1 از `emsipam-client` استفاده می‌کند و WinBox فقط `IP:PORT` دریافت می‌کند.
4. کارت Address Space ظرفیت کل، IP ثبت‌شده، IP آزاد، تعداد رنج و درصد مصرف را نشان می‌دهد.
5. افزودن Station از کنار AP، همان AP را خودکار به‌عنوان Parent حفظ می‌کند.
6. ارتفاع نقشه و جدول IP بر اساس ارتفاع واقعی صفحه و Zoom محاسبه می‌شود.
7. بازگشت به IPAM همان Address Space و CIDR قبلی را باز می‌کند.

نتیجه تست خودکار: 54 از 54 تست PASS. اجرای واقعی Docker در محیط ساخت به‌علت نبود Docker daemon انجام نشده و اسکریپت `scripts/docker-release-smoke.sh` برای اجرای نهایی روی میزبان Docker موجود است.
