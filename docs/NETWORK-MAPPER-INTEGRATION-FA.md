# راهنمای اتصال پروژهٔ نقشه شبکه

پروژهٔ نقشه شبکه یک سرویس مستقل خواهد بود و EMS IPAM برای آن یک رابط نسخه‌دار آماده دارد. به‌روزرسانی نقشه، نیازی به بازسازی بخش مدیریت IP ندارد.

## فعال‌سازی

1. در EMS IPAM با کاربر مدیر وارد شوید.
2. تنظیمات را باز کنید.
3. در بخش «پروژه نقشه شبکه»، نشانی سرویس مستقل را وارد و گزینهٔ فعال‌بودن را روشن کنید.
4. روی «ساخت توکن اتصال» بزنید.
5. توکن را همان لحظه کپی و در تنظیمات سرویس نقشه ذخیره کنید؛ مقدار کامل آن دوباره در EMS IPAM نمایش داده نمی‌شود.

## دریافت اطلاعات IPAM

```http
GET /api/integration/v1/snapshot
Authorization: Bearer YOUR_TOKEN
```

خروجی شامل این مجموعه‌هاست:

- شرکت‌ها و رابطهٔ شرکت مادر
- فضای آدرس‌دهی و CIDR
- تجهیزات ثبت‌شده و نام آن‌ها
- IP، MAC، سازنده، مدل، سریال، Firmware و VLAN
- فهرست پورت‌های ثبت‌شدهٔ هر تجهیز

هیچ رمز دستگاه، رمز پایش، کلید سامانه یا اطلاعات ورود کاربر در خروجی وجود ندارد.

## همگام‌سازی دستگاه کشف‌شده

```http
POST /api/integration/v1/hosts/sync
Authorization: Bearer YOUR_TOKEN
Content-Type: application/json
```

نمونهٔ بدنه:

```json
{
  "items": [
    {
      "ip": "192.168.20.10",
      "name": "SW-CORE-01",
      "type": "سوئیچ",
      "vendor": "Cisco",
      "model": "C9200",
      "mac": "00:11:22:33:44:55"
    }
  ]
}
```

رفتار همگام‌سازی:

- اگر IP در IPAM وجود داشته باشد، همان رکورد و نام ثبت‌شده برگردانده می‌شود.
- فیلد خالی رکورد موجود می‌تواند با اطلاعات کشف‌شده تکمیل شود؛ دادهٔ غیرخالی کاربر جایگزین نمی‌شود.
- اگر IP در یکی از رنج‌های موجود باشد ولی رکورد نداشته باشد، رکورد جدید ساخته می‌شود.
- اگر IP خارج از تمام رنج‌ها باشد، پاسخ `outside_range` برگردانده می‌شود و چیزی ساخته نمی‌شود.

## مرز مسئولیت

این رابط برای همگام‌سازی موجودی است. EMS IPAM هیچ دستور CLI، SNMP Write یا API Write برای تغییر کانفیگ سوئیچ اجرا نمی‌کند. کشف LLDP/CDP، خواندن VLAN و ترسیم ارتباط پورت‌ها در پروژهٔ مستقل نقشه پیاده‌سازی خواهد شد.

## غیرفعال‌کردن دسترسی

توکن‌ها در تنظیمات مدیر دیده می‌شوند و هر توکن را می‌توان مستقل غیرفعال کرد. پس از غیرفعال‌شدن، درخواست بعدی سرویس نقشه با پاسخ ۴۰۱ رد می‌شود.
