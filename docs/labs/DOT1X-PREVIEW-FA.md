# شبیه‌ساز مجوزدهی 802.1X — بدون EAP و بدون اعمال دسترسی

این ماژول فقط **نتیجه احتمالی مجوزدهی پس از تأیید هویت توسط یک EAP server معتبر** را محاسبه می‌کند. عبارت `authentication.source = "trusted-eap"` صرفاً یک فیلد سناریوی آزمایشی است؛ **اثبات رمزنگاری‌شده هویت نیست** و نباید از درخواست کاربر یا کلاینت شبکه پذیرفته شود. این ماژول را به مسیر واقعی Access-Accept وصل نکنید.

پیش‌نیاز برای استفاده عملی: FreeRADIUS/EAP، اعتبارسنجی گواهی و روش EAP، کنترل هویت NAS، ثبت Accounting، نگهداری امن shared secret، RBAC، audit و تست روی firmware مشخص. این موارد هنوز پیاده نشده‌اند.

سناریوها: برای کاربر تأییدشده با نقش واحد، می‌توان حالت VLAN ثابت یا Dynamic VLAN را پیش‌نمایش کرد. هویت تأییدنشده، NAS غیرفعال، نبود نقش، چند نقش متناقض، VLAN نامعتبر، داده تکراری و ارتباط بین شرکت‌ها همگی Reject می‌شوند. **هیچ fallback خودکار از EAP شکست‌خورده به MAB یا Guest VLAN وجود ندارد.**

از ریشه پروژه:

```bash
node --test docker-app/tests/radius-dot1x-policy-preview.test.mjs
```

این بسته صرفاً منطق آفلاین است؛ هیچ API، سرویس، دیتابیس یا تنظیمات سوئیچ را تغییر نمی‌دهد.
