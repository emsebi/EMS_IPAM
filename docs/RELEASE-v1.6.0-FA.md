# EMS IPAM v1.6.0

این انتشار نسخه تکمیل‌شده مبنای `1.5.1` در محدوده **BASE + IPAM + Radio موجود** است.

## BASE

- نقش محدود `Branch` در دیتابیس، API و مدیریت کاربران اضافه شد.
- Personnel برای Admin مستقیماً از منوی اصلی قابل دسترسی است.
- دسترسی Role ماژول از Capabilityهای `permissions` جدا شد.
- فهرست کامل Personnel فقط برای Admin قابل دریافت است.
- فقط دو زبان فارسی و انگلیسی در این پروژه فعال‌اند.
- متن Backup با سیاست عدم ذخیره رمز تجهیزات هماهنگ شد.
- Telnet در ذخیره تنظیمات ابزارها حفظ می‌شود.

## IPAM و Inventory

- فیلتر شرکت در Inventory روی نمایش، شمارش Type و CSV اعمال می‌شود.
- کارت Address Space در صفحه شرکت تعداد IP ثبت‌شده و درصد مصرف را نشان می‌دهد.
- دکمه «نمای شرکت» از IPAM به همان شرکت برمی‌گردد.
- Migration نقش‌ها روی PostgreSQL واقعی/سازگار، نصب تازه و اجرای دوباره آزمایش شد.

## Radio 1.1.0

- عملیات Edit، IPAM و Ping از هم جدا شدند.
- آخرین نتیجه Ping با وضعیت Online، Offline یا Unknown نمایش داده می‌شود.
- جستجوی Station، AP والد را از درخت حذف نمی‌کند.
- Stationهای بدون AP در بخش مستقل دیده می‌شوند.
- کاربران Read-only می‌توانند مشاهده، Ping و ورود به IPAM داشته باشند؛ ویرایش فقط برای Admin است.
- فیلدهای Radio بدون نصب ماژول نمایش داده نمی‌شوند و API نیز ثبت داده Radio را رد می‌کند.

## Installer

- منوی پنج‌گزینه‌ای شامل Backup دستی دیتابیس شد.
- `COOKIE_SECURE` در نصب تازه پرسیده می‌شود.
- ZIP استخراج‌شده بدون دانلود دوباره از GitHub نصب می‌شود.
- Update نصب‌شده همچنان نسخه جدید را از GitHub می‌گیرد، قبل از تغییر Backup می‌سازد و در خطا فایل‌های نسخه قبل را بازمی‌گرداند.
- کنترل مسیرهای خطرناک پیش از عملیات حذف اضافه شد.

## سازگاری

- دیتابیس و `.env` نسخه `1.5.1` در Update حفظ می‌شوند.
- افزونه Radio همراه Release است، اما BASE + IPAM با حذف پوشه `modules/radio` نیز مستقل می‌ماند.
