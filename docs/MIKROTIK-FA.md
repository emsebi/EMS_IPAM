# آموزش سادهٔ اتصال MikroTik به EMS IPAM

## روش پیش‌فرض

برای RouterOS v6 و v7 روش سادهٔ زیر انتخاب شده است:

| روش | پورت پیش‌فرض | Certificate | اطلاعات لازم در سامانه |
|---|---:|---|---|
| API | 8728 | لازم نیست | IP تجهیز، نام کاربری، رمز دلخواه |
| API-SSL | 8729 | لازم است | گزینهٔ پیشرفته و اختیاری |
| REST روی HTTPS | 443 | لازم است | گزینهٔ پیشرفته برای RouterOS v7 |

سامانه در روش ساده هیچ Certificate یا CA درخواست نمی‌کند. رمز می‌تواند هر مقدار دلخواه یا حتی خالی باشد. تنظیم Firewall نیز توسط سامانه تغییر نمی‌کند.

## تنظیم در سه مرحله

۱. تجهیز MikroTik را در صفحهٔ IP باز کنید و حالت رادیو را روی `AP` بگذارید.

۲. «پایش میکروتیک» را فعال و این موارد را وارد کنید:

- روش ارتباط: `روش ساده API`
- پورت: `8728`
- نام کاربری: برای مثال `ems-ipam`
- رمز: هر مقدار دلخواه؛ برای حفظ رمز قبلی خالی بماند

۳. روی «ساخت اسکریپت تنظیم میکروتیک» بزنید، اسکریپت را کپی و یک‌بار در Terminal روتر اجرا کنید. سپس اطلاعات تجهیز را ذخیره و «آزمایش ارتباط» را بزنید.

اسکریپت ساده فقط این کارها را انجام می‌دهد:

- ایجاد یا اصلاح گروه `ems-ipam` با مجوز `read,api`
- ایجاد یا اصلاح کاربر پایش
- فعال‌کردن سرویس `api` روی پورت انتخابی

دسترسی نوشتن، راه‌اندازی مجدد و مشاهدهٔ رمزهای روتر به کاربر داده نمی‌شود.

## استفاده از کاربر موجود

لازم نیست حتماً اسکریپت بسازید. اگر از قبل کاربری با مجوز `read,api` دارید، فقط همان نام کاربری و رمز را در فرم وارد کنید و سرویس API را فعال کنید:

```routeros
/ip/service/set api disabled=no port=8728
```

## دریافت وضعیت رادیو

پس از اتصال، سامانه ابتدا ساختار جدید را بررسی می‌کند و اگر موجود نبود سراغ ساختار قدیمی می‌رود:

```text
/interface/wifi/registration-table
/interface/wireless/registration-table
```

وضعیت آنلاین، MAC، IP دیده‌شده، SSID، سیگنال، نرخ ارسال و دریافت، حجم ترافیک، مدت اتصال و آخرین فعالیت در صورت ارائه‌شدن توسط مدل و نسخهٔ RouterOS ثبت می‌شوند. Identity، مدل، نسخه، Uptime، مصرف CPU و حافظهٔ AP نیز بالای همان کارت نمایش داده می‌شود.

بازهٔ پیش‌فرض بررسی پنج دقیقه است تا هر بار ورود API در Log میکروتیک تکرار نشود. مدیر می‌تواند بازه را بین یک تا ۶۰ دقیقه تغییر دهد یا در صورت نیاز «بررسی اکنون» را بزند.

## وضعیت‌های نمایش

- سبز: ارتباط موفق و اطلاعات دریافت شده است.
- زرد: هنوز نتیجه قطعی نیست یا خطای موقت رخ داده است.
- قرمز: پس از سه بار خطا، تجهیز آفلاین در نظر گرفته می‌شود.
- خاکستری: هنوز پایش نشده است.

## گزینه‌های پیشرفته

اگر بعداً ارتباط رمزگذاری‌شده خواستید، `API-SSL` یا `REST روی HTTPS` را انتخاب کنید. فقط در این دو حالت نام Certificate و CA لازم است. روش ساده برای کار عادی بدون این تنظیمات قابل استفاده است.

مراجع رسمی: [API و API-SSL](https://help.mikrotik.com/docs/spaces/ROS/pages/47579160/API)، [REST API](https://help.mikrotik.com/docs/spaces/ROS/pages/47579162/REST%20API)، [مدیریت کاربران](https://help.mikrotik.com/docs/spaces/ROS/pages/8978504/User) و [سرویس‌های IP](https://help.mikrotik.com/docs/spaces/ROS/pages/103841820/Services).
