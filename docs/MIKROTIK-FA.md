# آموزش اتصال امن MikroTik به EMS IPAM

## انتخاب روش اتصال

| نسخه | روش | پورت پیش‌فرض | کاربرد |
|---|---|---:|---|
| RouterOS v7 | REST روی HTTPS | 443 | روش اصلی و پیشنهادی |
| RouterOS v6 | API-SSL | 8729 | سازگاری امن با نسخه‌های قدیمی |

سامانه هر دو ساختار رادیویی جدید و قدیمی را بررسی می‌کند:

```text
/interface/wifi
/interface/wireless
```

## آماده‌سازی گواهی

سرویس امن MikroTik باید یک Certificate معتبر داشته باشد. نام DNS یا IP مدیریتی روتر باید در بخش SAN گواهی وجود داشته باشد. اگر گواهی توسط CA داخلی ساخته شده است، متن PEM گواهی CA را داخل فرم تجهیز در سامانه قرار دهید.

سامانه اعتبار TLS را بررسی می‌کند و گزینه‌ای برای نادیده‌گرفتن خطای گواهی ندارد.

## مراحل داخل سامانه

۱. تجهیز MikroTik را ایجاد یا ویرایش کنید.

۲. بخش «پایش MikroTik» را فعال کنید.

۳. روش اتصال را متناسب با نسخه انتخاب کنید.

۴. IP مدیریتی، پورت، نام کاربری، رمز قوی و CA را ثبت کنید.

۵. گزینهٔ «ساخت اسکریپت اتصال امن» را بزنید.

۶. IP سرور EMS IPAM، نام Certificate روی روتر و یک نام کاربری اختصاصی را وارد کنید.

۷. اسکریپت تولیدشده را در Terminal روتر اجرا کنید.

۸. به سامانه برگردید و «آزمایش ارتباط» را اجرا کنید.

## دسترسی ساخته‌شده روی روتر

برای RouterOS v7:

```text
read,rest-api
```

برای RouterOS v6:

```text
read,api
```

اسکریپت، کاربر را به IP سرور سامانه محدود می‌کند و فقط سرویس امن لازم را باز می‌گذارد. دسترسی‌های تغییر تنظیمات، راه‌اندازی مجدد و مشاهدهٔ رمزها به کاربر پایش داده نمی‌شوند.

## وضعیت‌های نمایش

- سبز: دستگاه آنلاین و اطلاعات پایش دریافت شده است.
- زرد: دستگاه پاسخ می‌دهد ولی اطلاعات رادیویی کامل نیست یا Station دیده نمی‌شود.
- نارنجی: IP در دسترس است ولی ورود امن به API ناموفق بوده است.
- قرمز: پس از سه بار خطا، دستگاه آفلاین در نظر گرفته می‌شود.
- خاکستری: هنوز پایش نشده یا اطلاعات قدیمی است.

بازهٔ پیش‌فرض پایش ۶۰ ثانیه است و از تنظیمات سامانه قابل تغییر است. برای دستگاه آفلاین فاصلهٔ درخواست‌ها تدریجی افزایش می‌یابد.

## توصیه‌های امنیتی

- سرویس مدیریتی را روی اینترنت عمومی باز نکنید.
- قانون Firewall را فقط برای IP سرور EMS IPAM مجاز کنید.
- برای هر سامانه یک کاربر اختصاصی بسازید.
- رمز پایش را با کاربران شرکت به اشتراک نگذارید.
- پس از تعویض گواهی، CA ثبت‌شده در سامانه را نیز به‌روزرسانی کنید.
- ساعت روتر و سرور باید دقیق باشد تا اعتبار گواهی درست بررسی شود.
