# لیست IPv4 ایران برای MikroTik

GitHub Actions هر روز حدود **۰۴:۱۷ به وقت تهران** اطلاعات RIPE را می‌گیرد، اعتبارسنجی می‌کند، روی RouterOS 6 و 7 در ماشین‌های CHR آزمایشی اجرا می‌کند و فقط پس از موفقیت فایل‌ها را منتشر می‌کند. سرور شخصی لازم نیست. اجرای زمان‌بندی GitHub ممکن است با تأخیر انجام شود.

## لینک‌های ثابت

| فایل | لینک دانلود |
|---|---|
| RouterOS 6 | [IR-IP_EMS-v6.rsc](https://raw.githubusercontent.com/emsebi/EMS_IPAM/main/feeds/iran/IR-IP_EMS-v6.rsc) |
| RouterOS 7 | [IR-IP_EMS-v7.rsc](https://raw.githubusercontent.com/emsebi/EMS_IPAM/main/feeds/iran/IR-IP_EMS-v7.rsc) |
| نصب آپدیتر، برای هر دو نسخه | [install-update.rsc](https://raw.githubusercontent.com/emsebi/EMS_IPAM/main/feeds/iran/install-update.rsc) |
| متن اسکریپت آپدیت | [update.rsc](https://raw.githubusercontent.com/emsebi/EMS_IPAM/main/feeds/iran/update.rsc) |
| مشخصات نسخه منتشرشده | [manifest.json](https://raw.githubusercontent.com/emsebi/EMS_IPAM/main/feeds/iran/manifest.json) |

## نصب و استفاده

۱. ساعت و تاریخ روتر باید درست باشد و روتر به GitHub Raw دسترسی HTTPS داشته باشد.

۲. فایل `install-update.rsc` را با مرورگر دانلود کنید و در **Files** در WinBox بارگذاری کنید. سپس با کاربر مدیر در Terminal اجرا کنید:

```routeros
/import file-name=install-update.rsc
```

این کار گواهی عمومی لازم برای اعتبارسنجی HTTPS و اسکریپت `IR-IP_EMS-update` را نصب می‌کند. استفاده از نسخه‌های به‌روز شاخه‌های 6 و 7 توصیه می‌شود؛ نسخه‌های دقیق آزمون در فایل‌های `test-routeros-6.json` و `test-routeros-7.json` ثبت می‌شوند.

۳. هر بار برای گرفتن آخرین لیست اجرا کنید:

```routeros
/system script run IR-IP_EMS-update
```

آپدیتر نسخه روتر را تشخیص می‌دهد و فایل مناسب را می‌گیرد. نام لیست در **IP → Firewall → Address Lists** برابر `IR-IP_EMS` است. هیچ قانون Firewall، NAT، Route یا Scheduler ساخته نمی‌شود.

برای وارد کردن دستی، فایل v6 یا v7 مناسب روتر را دانلود و در Files بارگذاری کنید و `/import file-name=IR-IP_EMS-v6.rsc` یا `/import file-name=IR-IP_EMS-v7.rsc` را اجرا کنید. این روش به آپدیتر نیاز ندارد.

## تاریخ شمسی

ردیف `1.1.2.7` در لیست **غیرفعال** است و تنها برای نمایش اطلاعات استفاده می‌شود:

```text
EMS:IR:META|...|RIPE=1405/07/26|Updated=1405/07/29 12:00 Tehran|IPv4=...|SHA=...
```

- `RIPE`: تاریخ شمسی داده منبع.
- `Updated`: تاریخ و ساعت شمسی ساخت فایل در GitHub، به وقت تهران. فقط بعد از اعمال موفق لیست روی روتر، این کامنت تغییر می‌کند؛ این مقدار زمان اجرای محلی روتر نیست.
- `IPv4`: تعداد پیشوندهای تجمیع‌شده.

ارقام تاریخ لاتین‌اند تا نمایش روی RouterOS 6 هم ساده باشد. داده RIPE ممکن است چند روز عقب‌تر از زمان دریافت باشد؛ هر دو تاریخ عمداً نمایش داده می‌شوند.

## رفتار هنگام خطا

- لیست خالی، داده غیرعمومی، ورودی نامعتبر، داده قدیمی‌تر از هفت روز، عقب‌رفتن تاریخ منبع و تغییر غیرعادی پوشش قبل از انتشار رد می‌شوند.
- HTTPS با `check-certificate=yes` بررسی می‌شود؛ فایل دانلودشده باید اندازه اعلام‌شده را داشته باشد. سپس همه پیشوندها در لیست موقت غیرفعال بررسی می‌شوند.
- ابتدا پیشوندهای جدید اضافه و سپس پیشوندهای حذف‌شده RIPE برداشته می‌شوند. حذف کامل لیست قبل از دانلود وجود ندارد. در خطاهای قابل‌گرفتن هنگام اعمال، تغییرات برگردانده می‌شوند.
- خاموشی ناگهانی یا توقف دستی اسکریپت تراکنش اتمیک نیست؛ اجرای موفق بعدی لیست را همگام می‌کند. اگر کار متوقف شده ولی قفل باقی مانده، پس از اطمینان از نبودن کار فعال در `/system script job print`، متغیرهای `emsIRApplyBusy` و `emsIRFetchBusy` را در همان حساب اجراکننده `false` کنید، یا روتر را در زمان مناسب راه‌اندازی مجدد کنید.
- `IR-IP_EMS` و `IR-IP_EMS__stage` برای این ابزار رزرو هستند؛ ورودی‌های دستی را در لیست دیگری نگه دارید. وجود ورودی ناشناس در لیست اصلی باعث توقف آپدیت می‌شود.
- در شکست تولید یا تست، GitHub فایل‌های سالم قبلی را حفظ می‌کند. صفحه [Actions](https://github.com/emsebi/EMS_IPAM/actions/workflows/iran-ip-feed.yml) نتیجه اجرا را نشان می‌دهد. در صورت تغییر ریشه گواهی GitHub، نصب‌کننده جدید را دوباره وارد کنید.

## منبع و محدوده

منبع مستقیم [RIPEstat Country Resource List](https://stat.ripe.net/data/country-resource-list/data.json?resource=IR&v4_format=prefix) است. پیشوندهای هم‌جوار فقط وقتی تجمیع می‌شوند که پوشش دقیقاً یکسان بماند. هیچ محدوده خصوصی یا تکمیلی به داده RIPE اضافه نمی‌شود. این خروجی **IPv4 ثبت‌شده با کد کشور IR** است؛ تضمین محل فیزیکی سرویس یا تعرفه ترافیک داخلی نیست.

زمان‌بندی Actions تضمین دقیقه دقیق ندارد. GitHub ممکن است زمان‌بندی مخزن عمومی را پس از ۶۰ روز بی‌فعالیتی متوقف کند؛ انتشار روزانه موفق در این مخزن commit ایجاد می‌کند. برای خطاها اعلان‌های Actions حساب خود را فعال نگه دارید.

## توسعه

کد در [`tools/iran-ip`](../../tools/iran-ip) است. تست CHR فقط روی ماشین مجازی موقت GitHub-hosted اجرا می‌شود و به روتر یا سرور شخصی متصل نمی‌شود. استثنای تغییر بزرگ فقط با بازبینی منبع و اجرای دستی Workflow با ورودی `accept_large_change` قابل تأیید است.
